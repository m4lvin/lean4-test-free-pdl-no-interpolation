# Test-free Propositional Dynamic Logic does not have Craig Interpolation, in Lean 4

We prove that
[Propositional Dynamic Logic (PDL)](https://plato.stanford.edu/entries/logic-dynamic/)
**without tests** does not have the
[Craig Interpolation](https://en.wikipedia.org/wiki/Craig_interpolation) property.
